# Ручная проверка (владелец)

Агенты не запускают docker и не проверяют веб глазами. Эти шаги выполняет владелец. Результат каждого шага записывается в строке «результат».

## П1. Docker (release gate)

Без П1 rev3 не считается готовым.

1. `docker compose build`
   Ожидается: сборка завершается без ошибок.
   результат: ___
2. `docker compose up -d`, затем `docker compose exec sysadm sh -c '/data/opencode/bin/opencode --version && id -u'`
   Ожидается: при первом запуске сервер сам скачал opencode в volume (в логе `installing opencode 2.x.y`), версия последняя 2.x, uid `1000`.
   результат: ___
3. `docker compose run --rm --no-deps sysadm test -r /app/packages/plugin/src/index.ts && echo plugin-ok`
   Ожидается: строка `plugin-ok`.
   результат: ___
4. `docker compose up -d`, затем `docker compose ps`
   Ожидается: сервис `sysadm` в состоянии healthy, контейнера `opencode` нет.
   результат: ___
5. `docker compose logs sysadm | grep -i opencode`
   Ожидается: строка о запуске дочернего процесса opencode, без ошибок загрузки плагина.
   результат: ___
6. `docker compose exec sysadm sh -c 'cat /proc/$(pgrep -f "opencode serve")/environ | tr "\0" "\n" | grep -c SYSADM_MASTER_KEY'`
   Ожидается: `0`.
   результат: ___

## П2. E2E с реальной моделью и тестовой ВМ

Агент не выполняет этот шаг: нет модели и тестовой ВМ.

1. Задайте `E2E_PROVIDER_KEY`, `E2E_MODEL`, `E2E_SSH_HOST`, `E2E_SSH_USER`, `E2E_SSH_KEY_FILE`.
2. `bash scripts/e2e.sh`
   Ожидается: строка `E2E OK`. Без переменных скрипт печатает `E2E SKIPPED` и завершается с кодом 2.
   результат: ___

## П3. Веб глазами

1. Вход: пароль и TOTP.
   Ожидается: открывается дерево инвентаря.
   результат: ___
2. Задача с подтверждением: создать задачу `uptime`, подтвердить запрос разрешения.
   Ожидается: задача завершается, в аудите есть запись `exec`.
   результат: ___
3. Страница «Система» (меню «Система»): перезапустить opencode.
   Ожидается: после перезапуска состояние `running` в течение 30 секунд.
   результат: ___
4. Токены («Настройки → API-токены»): создать токен `read`.
   Ожидается: токен показан один раз, после перезагрузки страницы в списке только метаданные.
   результат: ___
5. Отозвать токен.
   Ожидается: в списке статус «отозван», запросы с ним получают 401.
   результат: ___
