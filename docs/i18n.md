# Языки интерфейса

Интерфейс переведён на русский и английский. Ядро — `apps/web/src/i18n/index.ts`, словари:

- `apps/web/src/i18n/app.ts` — общий интерфейс (панели, чат, карточка узла, вход);
- `apps/web/src/i18n/settings.ts` — окно настроек;
- `plugins/<id>/web/i18n.ts` — у каждого плагина свой словарь.

Язык выбирается в «Настройки → Общие» или кнопкой в подвале левой панели, хранится в `localStorage` (`sysadm.lang`). Без выбора берётся язык браузера (`ru*` → русский, иначе английский). Смена языка перезагружает страницу.

## Как добавить язык

1. В `LANGS` (`apps/web/src/i18n/index.ts`) добавить `{ id: "de", label: "Deutsch" }`.
2. Поправить `locale` там же, если формат дат и чисел должен быть не `en-US`.
3. В каждый вызов `defineMessages()` добавить блок `de: { … }`. Блок может быть неполным: недостающие ключи берутся из английского.
4. `bun run typecheck` — английский словарь обязан иметь все ключи русского, иначе tsc упадёт.

## Правила для строк

- Строка в коде — только через `t("ключ")`. Русский словарь — исходный.
- Подстановки: `t("tasks.count", { count: 3, name })` и `{name}` в тексте.
- Множественное число: значение `{ one, few, many, other }` (правила `Intl.PluralRules`, нужен `count`).
- Даты и числа: `fmtDate`, `fmtTime`, `fmtDateTime`, `fmtNumber` вместо `toLocale*()`.
- Файлы, которые импортируют тесты `bun test`, подключают словари относительным путём (`../i18n/app`), не через `@/`.

Не переведено: сообщения об ошибках API сервера и промпты агентов (агенты отвечают на языке пользователя).
